# Update V9.11.0

## Enthaltene Änderungen

- neuer Name: **ProFlex / GTS / Angebotsmanager**
- allgemeine Begriffe für Angebote, Durchführungen, Teilnehmende und Zuteilung
- acht übersichtliche Hauptbereiche
- leerer Programmstart und „Aktuelles Projekt leeren“
- Projekteinstellung für Schulprojekt oder allgemeine Veranstaltung
- Klassenangabe erforderlich oder optional
- Klassen mit `G/g` gymnasial, andere vorhandene Klassen regional
- ein bis vier erwartete Wünsche einstellbar
- toleranter Umfrageimport mit kombiniertem Namen und optionalem Zeitstempel
- Einwahlprüfung für fehlende, doppelte und unbekannte Wünsche
- Einwahlkontrolle gegen eine Schüler-/Klassenliste
- Angebots-, Schülerlisten- und Umfragevorlagen im Bereich Datenaustausch
- weiterhin kompatibel mit alten JSON- und Excel-Dateien

## GitHub Pages

Der fertige Ordner `docs` kann ohne eigenen Build über `main` → `/docs` veröffentlicht werden.
