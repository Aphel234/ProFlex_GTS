# Update V9.8.1 – Lösungsvergleich

Der Knopf **„Drei Lösungen vergleichen“** gibt jetzt sofort sichtbare Rückmeldung:

- Fortschritt `1 von 3`, `2 von 3`, `3 von 3`
- Name des gerade berechneten Profils
- deaktivierter Knopf während der Berechnung
- je Profil sechs Qualitätsvarianten
- verständliche Fehlermeldung bei einem unerwarteten Abbruch

Damit wirkt die Anwendung bei größeren Schülerzahlen nicht mehr scheinbar reaktionslos.
